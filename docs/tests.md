## 評分欄

- **對答案**：Q1–Q3 合格要點命中幾多（/3）
- **作假出處**：將語料冇嘅句子講成 Hormozi 講過（作者用 518 部逐字稿 grep 核）
- **作數字**：俾出語料冇嘅本地數字
- **標推測**：Q5 有冇標「推測／語料冇直接講」
- **批評者角度**：Q6 有冇引用顧問卡批評者段
- **自稱席位**：答案唔應該自稱第幾席（本 skill 係單席）
